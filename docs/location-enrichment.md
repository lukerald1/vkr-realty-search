# География и инфраструктура

Данные OSM загружаются отдельно от поиска. Адреса жилья внешним сервисам не передаются. Атрибуция: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright).

## Покрытие

- 30 192 объекта, 12 категорий инфраструктуры; сведения рассчитаны для 26 322 объявлений в пределах 3 км.
- Контуры 800 школ и 1418 парков/садов. Для остальных объектов используются точки или центры; способ указан в карточке.
- 18 районов и 3 муниципальных полигона; район определён для 26 325 объявлений, 203 остаются без подтверждённой привязки по координатам.
- Справочник RAEX: 7 учреждений / 8 объектов карты. Места, год, источник и сопоставление — в config/school-ratings.json. Это конкурентоспособность выпускников, не общая оценка школы.

Координаты объявлений независимо не проверены. Расстояние до территории не равно пути до входа. Округление вверх сохраняет обязательный предел: 500,4 м не проходит фильтр 500 м. Отсутствие объекта в снимке не доказывает его отсутствие в городе.

## Обновление

Нужны исходные выгрузки и основной каталог. Перед массовым обновлением остановить сайт.

~~~powershell
node scripts/import-data.mjs "продажа.jsonl" "аренда.jsonl"
powershell -File scripts/fetch-infrastructure.ps1
powershell -File scripts/fetch-infrastructure.ps1 -Layer school -Server main
powershell -File scripts/fetch-infrastructure.ps1 -Layer park -Server main
npm run enrich:infrastructure
powershell -File scripts/fetch-locations.ps1 -Server main
npm run enrich:locations
~~~

Для прокси добавить -Proxy http://127.0.0.1:7890. При перегрузке повторять позже, не запускать частые циклы запросов. Географическое обогащение ожидает исходные файлы в backup 06.10/; инфраструктурный скрипт также принимает пути аргументами.

Загрузчики проверяют полноту слоёв до замены файлов. Обогащение сохраняет резервную копию SQLite и выполняется в транзакции. После переимпорта повторить оба обогащения.

Снимки и отчёты: data/infrastructure/. Резервные копии: artifacts/backups/. Они не входят в Git. Даты и SHA-256 записаны в отчётах.
