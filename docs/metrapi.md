# Metrapi: подключение и условия

Проверено 21 октября 2026 года: [документация](https://metrapi.ru/api-docs.html), [оферта](https://metrapi.ru/offer.html).

Технически: `GET https://api.metrapi.ru/v1/items`, ключ в серверном заголовке `X-Api-Key`. Чтение — максимум один запрос в две секунды на ключ. Для `429` задержка приходит в JSON `detail.retry_after`; немедленные повторы расходуют квоту. Есть общий суточный лимит. Для дублей используется `dedupe=true`.

Адаптер проекта: одна страница до 50 объектов, кэш на минуту, ограничение частоты в одном процессе, таймаут, без автоматических повторов. Выдача явно предупреждает, если есть продолжение. Для нескольких процессов понадобится общий ограничитель.

Оферта запрещает автоматизацию веб-кабинета, передачу ключа и распространение данных/производные сервисы без письменного согласия. Ключ должен оставаться на сервере. Сам доступ к API не заменяет отдельное разрешение на публикацию данных.

Студент предоставил в переписке письмо провайдера с разрешением свободно использовать данные для ВКР. Письмо говорит о доступе «по июнь включительно», без года в приведённом фрагменте. Уточнить дату в кабинете и сохранить оригинал письма отдельно от репозитория.

Код запускается локально; реальная выгрузка и `.env` исключены из Git. Свежий checkout использует вымышленные примеры. Публичное развёртывание и передача выгрузки отдельно не выполнялись.
