# Импорт базы Петербурга

Файлы пользователя: `spb_sale.jsonl` и `spb_rent.jsonl` из папки `backup 06.10`. Импорт выполнен 22.10.2026 по Москве. Размер исходных файлов суммарно около 249 МБ; исходники не менялись.

Проверка баланса: 26 528 + 12 427 + 602 + 291 + 662 = 40 510.

Все читаемые записи имеют `city=spb`, но это зона сбора провайдера, включающая окрестности. Для включения требуются регион Санкт-Петербург и распознанный населённый пункт внутри субъекта. Пушкин, Петергоф и другие муниципальные города Петербурга включаются; Мурино, Кудрово и Ленинградская область — нет. Пустые/противоречивые поля не угадываются по описанию.

Дедупликация: ключ `deal_type + group_id`; при отсутствии группы — `deal_type + source + source_id`. При совпадении остаётся первая допустимая запись из входной последовательности. Это не гарантирует отсутствие всех дублей: одинаковые квартиры с разными `group_id` могут сохраниться. Склейка по похожим адресам требует отдельной проверки.

По сырой читаемой выборке: для аренды у 835 записей нет минут до метро, у 3697 — площади кухни; для продажи — у 4388 и 7219 соответственно. Жёсткое условие по неизвестному полю исключает запись; мягкое пожелание не получает положительного вклада без подтверждающего значения.

Полный локальный отчёт с номерами повреждённых строк: `data/import-report.json`. В нём нет текстов объявлений, телефонов или ключей. Каталог, журнал сессий, сырые JSONL и cursor исключены из Git. Агрегаты в этом документе не свидетельствуют об актуальности предложений и не описывают весь рынок.
