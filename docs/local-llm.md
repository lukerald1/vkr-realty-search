# Локальная модель

Используется Qwen3 8B через Ollama. По умолчанию npm start работает без модели, по правилам.

## Запуск

1. Установить Ollama с официального сайта или распаковать её в artifacts/runtime/ollama/.
2. Запустить start-local-ai.cmd. Нужен Node.js 24+ в PATH.
3. Открыть адрес из терминала, обычно http://127.0.0.1:3100.

Первый запуск скачивает qwen3:8b. Модели хранятся в artifacts/runtime/models/. Уже запущенная Ollama использует своё хранилище. Скрипт не меняет .env.

При VPN с Fake-IP использовать start-local-ai-proxy.cmd. По умолчанию прокси http://127.0.0.1:7890; другой адрес задаётся через PROSTOR_HTTPS_PROXY. Прокси применяется только к запускаемым процессам. Защита Ollama не отключается.

Ctrl+C завершает сайт и Ollama, если её запустил этот скрипт. Чужой ранее запущенный экземпляр не останавливается.

## Поведение

- Только локальный адрес Ollama; облачные имена моделей запрещены.
- Reasoning включён для Qwen3, контекст 4096, тайм-аут до 90 секунд.
- Схема, типы, диапазоны и противоречия проверяются сервером.
- Кэш разбора на 15 минут разделён по сессиям; сортировка и пагинация не требуют повторного разбора.
- При ошибке показано сообщение; автоматического перехода с модели на правила нет.

## Проверки и ограничения

Текущий промпт — extractor-v8. Два сквозных запроса покупки/аренды проверены: около 18,6 и 27,3 с. Это проверка интеграции, не оценка общей точности.

Ранее модель путала «однушку» со студией. Сервер обнаружил конфликт; после уточнения словаря диагностический повтор прошёл. Старые проверки v6/v7 не подтверждают качество v8. Нужен независимый набор запросов и измерение задержки.

Платные API не подключены. Ключи и бюджет облачного провайдера настраиваются отдельно.
