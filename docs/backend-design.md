# Архитектура

Браузер → HTTP API на Node.js → SQLite. Внешние пакеты для запуска не нужны.

- search.mjs — нормализация, условия и ранжирование.
- extractor.mjs — схема ответа LLM, проверка, кэш и транспорт Ollama.
- catalog.mjs — SQL-фильтры, сортировка и пагинация.
- locations.mjs / area-boundaries.mjs — территории и полигоны.
- infrastructure.mjs — близость инфраструктуры и подтверждённые школьные бейджи.
- rental.mjs — условия аренды из полей источника.
- activity.mjs / saved.mjs — история, события и избранное.
- metrapi.mjs — адаптер объявлений; живая выдача пока ограничена одной страницей.

LLM выделяет условия, сервер проверяет их и применяет обязательные фильтры. Затем рассчитываются предпочтения. Модель не пишет SQL и не получает весь каталог или ключ Metrapi. Сортировка выполняется до пагинации.

Ранжирование эвристическое. Для оценки конверсии нужны пользовательские задания и отдельный эксперимент. Открытие карточки не считается сделкой.

Сессии разделены cookie; события принимаются только для выданных этой сессии объектов. Это не полноценные аккаунты. Публичный запуск требует HTTPS, авторизации, лимитов запросов и правил хранения истории.
