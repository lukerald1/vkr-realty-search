# Простор · ВКР

Тема: «Повышение конверсии пользователей риэлторской платформы за счёт поиска на естественном языке».

Пользователь описывает желаемое жильё своими словами. Система выделяет обязательные ограничения, мягкие предпочтения и непроверяемые условия, получает подходящие объявления через Metrapi и ранжирует их с объяснением соответствия запросу.

Паспорт темы: https://github.com/fa-un/vkr-constructor/blob/main/cases/realt-semanticheskiy-poisk.md

## Текущее состояние

Версия 0.1: локальное веб-приложение с главной, отдельной выдачей, фильтрами, объяснением подбора, карточками и избранным. **LLM и обученный ранжировщик ещё не подключены**: разбор и сортировка выполняются по правилам. Серверный адаптер Metrapi подготовлен, но живые запросы ещё не проверены.

## Запуск

Требуется Node.js 22+ (проверено на 24.19). Устанавливать зависимости не нужно.

```sh
npm start
```

Открыть http://127.0.0.1:3100. Без npm: `node --env-file-if-exists=.env apps/server.mjs`. В Windows можно запустить `start.cmd` двойным щелчком; он также умеет найти Node из установленного Codex runtime.

По умолчанию читается локальный `test_spb_sale.jsonl` из корня. Если файла нет, приложение использует 12 **вымышленных учебных объектов**. Выгрузка не входит в Git. Её путь можно задать через `SNAPSHOT_PATH` в `.env`.

Проверки: `npm test` или `node --test tests/*.test.mjs`.

## Что работает и какие есть ограничения

- Поиск по описанию: основные шаблоны комнатности, бюджета, площади, метро, балкона и этажей; распознанные условия можно проверить и изменить.
- Обязательные ограничения не ослабляются; неизвестное значение не считается совпадением. Мягкие предпочтения к метро и кухне меняют порядок выдачи.
- Дубли склеиваются по `group_id`; пояснения не выдаются за вероятность соответствия.
- Избранное хранится в браузере, без синхронизации между устройствами. Объекты, исчезнувшие из доступной выборки, в нём не отображаются.
- Карточки показывают реальные значения из снимка. Дата файла — время его изменения, а не подтверждение актуальности объявлений. Актуальность проверяют на исходной площадке.
- Произвольные фразы пока могут быть поняты частично. Некоторые неподдерживаемые критерии выделяются отдельно, остальные слова могут не учитываться.
- Нет аккаунтов, общей истории сессий, карты и обучающей разметки. Рост конверсии не измерялся. Главная использует сгенерированную архитектурную иллюстрацию, а не фото реального предложения.

## Живой API

1. Скопировать `.env.example` в `.env`.
2. Локально заполнить `METRAPI_API_KEY`, поставить `DATA_MODE=metrapi`.
3. Перезапустить сервер. Главная сама не расходует запросы; обращение к провайдеру происходит при поиске.

Не вставлять ключ в браузерный код или GitHub. Сервер отдаёт только поля интерфейса, без телефонов и продавцов. Подготовлены кэш на минуту, таймаут и ограничение частоты в одном процессе. Автоматических повторов нет. Загружается до 50 кандидатов; наличие продолжения обозначается в выдаче. Полный обход страниц — следующая итерация.

Сервер доступен только на loopback. Перед развёртыванием на виртуальной машине нужны аутентификация, HTTPS, общий ограничитель запросов и настройки хранения. [Документация и условия Metrapi](docs/metrapi.md).

## Структура

- `docs/plan.md` — план, текущая итерация и критерии готовности.
- `thesis/README.md` — структура текста диплома.
- `AGENTS.md` — правила для агента разработки.
- `apps/public/` — интерфейс, стили, изображения.
- `apps/server.mjs` — HTTP-сервер и API приложения.
- `apps/search.mjs` — извлечение условий, фильтры, ранжирование.
- `apps/metrapi.mjs` — адаптер провайдера.
- `apps/demo.mjs` — вымышленные учебные примеры.
- `tests/` — проверки поиска и адаптера.
- `.github/workflows/checks.yml` — автоматические проверки при push и PR.

## Совместная работа

Одна задача → отдельная ветка → небольшое изменение → проверка → pull request. В описании pull request указывать результат, способ проверки и ограничения. Научрук проверяет конкретную итерацию, а не весь проект целиком.

Ключи Metrapi и LLM хранятся только на сервере в переменных окружения. Реальные выгрузки и персональные данные не публикуются автоматически.
