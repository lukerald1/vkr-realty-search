# Простор

Поиск квартир Санкт-Петербурга для покупки и аренды: обычные фильтры и запросы на русском языке. Учебный проект для ВКР.

![Интерфейс](docs/screenshots/home.jpg)

## Что работает

- Локальная Qwen3 8B через Ollama: разбор запроса, проверка условий, уточнения, кэш.
- Фильтры квартиры, несколько районов и станций метро, исключения территорий.
- Районы, местности и условные зоны «север», «юг», «центр» с указанным составом.
- 12 категорий инфраструктуры: расстояния, приоритет пожеланий, объяснения в карточках.
- Рейтинг RAEX для 7 проверенных школ. Для 800 школ и 1418 парков загружены контуры.
- Условия аренды: животные, дети, залог, комиссия — по данным объявления.
- Избранное, история поиска, сортировка, пагинация и журнал действий.

## Запуск

Нужен Node.js 24+. Зависимости устанавливать не требуется.

~~~sh
npm start
~~~

Адрес: http://127.0.0.1:3100. В Windows можно запустить start.cmd.
С локальной моделью — start-local-ai.cmd. [Настройка Ollama](docs/local-llm.md).

Без локальной базы открываются 12 вымышленных примеров. Реальные данные, ключи, модели и история пользователей в Git не входят.

## Данные и ограничения

Локальная база: 26 528 исторических объявлений Metrapi — 18 987 продаж и 7541 аренда. Актуальность нужно проверять у источника. [Импорт и качество](docs/data-quality.md).

Инфраструктура: 30 192 объекта © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Расстояния по прямой до территории, точки или центра — способ указан в карточке. Пешие маршруты, полный бюджет с ЖКУ, тишина и безопасность не подтверждаются.

Обязательные условия не ослабляются при пустой выдаче. Ранжирование пока по правилам. Рост конверсии не измерен. Публичный хостинг и облачная модель не подключены.
