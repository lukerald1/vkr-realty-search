# Правила работы с проектом

- Выполняй изменения небольшими проверяемыми итерациями по `docs/plan.md`.
- Перед изменениями изучай текущие файлы; сохраняй пользовательские материалы.
- Обновляй README и план, когда меняется реальный статус проекта.
- Не публикуй API-ключи, `.env`, исходные выгрузки, персональные данные и экспериментальные загрузчики без проверки.
- Разделяй обязательные фильтры, мягкие предпочтения и непроверяемые условия. Не ослабляй обязательные условия скрыто.
- Не выдумывай цены, признаки объектов, оценки качества и результаты экспериментов.
- Отделяй демонстрационные данные, эвристический score и обученное ранжирование.
- Для изменения логики поиска проверяй значимые сценарии, включая пустую выдачу и неподдерживаемые критерии.
- Не отправляй запросы к платным API без согласованной конфигурации и бюджета.
- В конце итерации сообщай, что изменено, как проверено и что осталось.
