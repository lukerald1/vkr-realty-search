# Текст ВКР

Будущие документы:

1. Введение.
2. Глава 1 — теоретические основы и обзор решений.
3. Глава 2 — анализ объекта, требования, AS-IS и TO-BE, архитектура.
4. Глава 3 — реализация, эксперименты, план внедрения и экономика.
5. Заключение, список источников и приложения.

Пока это структура, а не написанные главы. Конкретное оглавление согласовать с научруком и требованиями кафедры. Для каждого источника сохранять ссылку и дату обращения; для каждого результата — данные, методику и воспроизводимый эксперимент. Организацию и исходные показатели из паспорта считать предположениями до подтверждения.
